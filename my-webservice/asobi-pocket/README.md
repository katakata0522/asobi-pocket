# あそびポケット (Asobi Pocket) 🎲

出先・待ち時間・飲み会・ドライブで大活躍！  
スマホ1台・道具なしで多人数ですぐ盛り上がるパーティーゲーム＆暇つぶし図鑑ツール集。

---

## 🌟 主な特徴 ＆ 機能

### 1. 🎮 スマホ1台で遊べる実践ゲームマスターツール集（全31種類）
代表的なゲーム・ツール：
- **🧶 ito（イト・価値観連想ゲーム）**: 1〜100の数字を配り、お題の例えで小さい順に並べる協力ゲーム。**カードのリアルタイム並び替え ＆ 1人2枚のマスターモード対応！**
- **☀️ 朝それ（朝までそれ正解）**: 「『あ』で始まる怖いものは？」などの頭文字×テーマジェネレーター。**濁音・半濁音対応 ＆ Xワンタップシェア機能！**
- **🌕 ワンナイト人狼**: 司会者不要！役職配布、夜のアクション、朝の議論タイマー、投票までスマホ1台で完結。
- **📜 詠み人知らず（リレー五七五）**: 1人5文字ずつ書いて回す！奇跡の合作名句・迷句が誕生する大爆笑ゲーム。
- **⚡ 罰ゲーム＆ミッションルーレット**: 負けた人に課す安全で誰もが笑えるミッション即決ツール。
- **🐺 ワードウルフ**: お題配り、タイマー、投票集計、役職オープンまでスマホ1台で完結。
- **💣 爆弾タイマー ＆ 古今東西**: 画面が徐々に過熱する爆発タイマー ＆ ラリー回数カウンター。
- **🈲 カタカナ禁止ゲーム（ボブジテン風）**: カタカナを使わずに説明！スコアボード ＆ タイマー機能。
- **👆 指置きロシアンルーレット（Chwazi風）**: 画面に指を置くだけで親決め・奢り決め（マルチタッチ対応）。
- **⚖️ 究極の2択 ＆ 深掘りトークガチャ**: 盛り上がる質問・議論ネタを多数収録。
- **🐢 ウミガメのスープ（水平思考クイズ）**: 出題者用ヒント＆真相解答トグル付き。
- **⏱️ 体内時計ジャスト対決**: 3秒/5秒/10秒/7.77秒の秒数当てゲーム。
- **🚫 NGワードゲーム / 🎴 スマホ額当てインディアンポーカー**

### 2. 📚 圧倒的なコンテンツボリューム（合計1000問以上収録）
- 各ゲームに初心者から上級者まで楽しめる厳選お題プリセットを大量収録。

### 3. ✨ リッチで洗練されたUI/UX（ゼロ依存・超軽量）
- **🎉 紙吹雪（Confetti）エンジン**: 成功時やゲームクリア時に画面全体を彩る特製Canvasパーティクル。
- **🔔 トースト通知システム**: お気に入り追加やリンクコピーをスマートにフィードバック。
- **📱 モバイルボトムナビゲーション**: スマホ片手で親指操作できる快適なナビゲーションバー。
- **🌙 ダークモード対応**: 夜の車内やバーでも目に優しいダークネイビーUI（自動保存）。
- **🔊 Web Audio API 効果音**: 外部音声ファイル不要のシンセサウンド（タップ音、爆発音、ファンファーレ等）。
- **📴 PWA 完全オフライン対応**: 地下の居酒屋や山道ドライブでも電波なしでサクサク動作。
- **⚡ 超高速レスポンス**: `touch-action: manipulation` による300msタップ遅延の物理的排除 ＆ 事前インデックス検索。

## 🛠️ 技術スタック
- **Frontend**: HTML5, CSS3 (Modern Flex/Grid/Custom Properties), Vanilla JavaScript (ES6+)
- **Audio**: Web Audio API (Synthesizer Sound Engine)
- **Animation**: HTML5 Canvas (Confetti Particles Engine)
- **Storage**: LocalStorage Wrapper (Safe Error Handling)
- **PWA**: Service Worker (Network-First + Offline Fallback), Web App Manifest
- **SEO**: Schema.org JSON-LD Structured Data, OGP Meta Tags
